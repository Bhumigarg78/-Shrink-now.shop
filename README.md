# Shrink-Now.shop

The world's most advanced browser-based media compression tool. Fast, secure, and professional.

## Features

- **Image Compression**: Compress PNG, JPG, WebP with customizable quality.
- **Video Compression**: Reduce video size using FFmpeg.wasm technology.
- **PDF Optimization**: Shrink PDF files by optimizing internal structures.
- **AI Hashtag Generator**: Generate platform-specific viral hashtags for social media.
- **100% Secure**: Your files never leave your computer. Privacy guaranteed.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Framer Motion, Lucide React
- **Backend**: Node.js, Express, MongoDB
- **Processing**: browser-image-compression, FFmpeg.wasm, pdf-lib

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- MongoDB

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   cd server && npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Start the backend server:
   ```bash
   npm run server
   ```
